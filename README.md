# Bank Account Management System

## About The Project

This repository contains a C++ application designed to simulate the creation and management of a bank account. It serves as a practical implementation of Object-Oriented Programming (OOP) concepts in C++, providing a straightforward console interface for basic banking operations.

The project also includes a test suite to ensure the reliability and correctness of the core logic, implemented using the Google Test framework.

## Features

* **Account Creation:** Initialize a new bank account with the account holder's details.
* **Deposit (Versamento):** Add funds to the current account balance.
* **Withdrawal (Prelievo):** Withdraw funds from the account (includes checks to prevent overdrafts).
* **Balance Inquiry (Saldo):** View the current available balance and account details.
* **Unit Testing:** Automated tests built with Google Test to verify the mathematical and logical operations of the account.

## Built With

* C++
* [Google Test](https://github.com/google/googletest) (for unit testing)
